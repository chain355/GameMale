# GameMale Native

一个**非官方**的 GameMale 论坛 Android 客户端，用原生 Compose（COUI / ColorOS 17 风格）把 Discuz 论坛重做成移动端阅读体验。

> 本项目与 GameMale 官方无关，仅作个人学习与自用。所有帖子内容、图片、附件的版权归论坛及原帖作者所有，使用时请遵守论坛规则，不要用于商业用途或批量抓取。

本仓库初始代码全部由 AI 完成，后续若有其他协作者会写入贡献者名单。公开出来是给同样想改造 Discuz 阅读体验的人做参考，不保证生产可用。

当前版本：`5.0.0`（versionCode 119；版本号语义为「主.功能.修复」，加功能升中位、修问题升末位），实测机 OnePlus PLK110 / Android 17 (API 37)，`targetSdk 37`，单 APK 支持 Android 12+。

## 它是什么

不套壳、不注入 CSS、不渲染网页。整个 App 是原生 Compose 界面，数据来自一个 **1dp 的隐藏 WebView**：它负责过 Cloudflare 校验、带上登录 Cookie 取回 HTML，然后交给 Jsoup 解析成原生数据模型。

## 功能

- **收藏**：帖子详情页头像菜单里的五角星图标可一键收藏帖子，重复点击取消；底栏第三个板块「收藏」列出收藏过的帖子，整页交互复用浏览记录（独立滚动位置、长按多选、批量移除、一键清空），收藏数据单独存本地，上限 200 条。底栏「收藏」按钮支持单击回顶：列表不在顶部时单击滚回顶部，已经在顶部时单击不做任何操作。
- **浏览记录**：底部导航第四项「浏览记录」，按打开时间倒序列出看过的帖子（同帖去重、只留最近一次），点条目直接打开；一级页，滚动位置独立记忆，可一键清空，也能长按进入多选批量删除。像书签一样只存在本地、不跟账号走，清缓存也不会删掉；卡片下方展示帖子预览图（和板块列表同一套排版），图片字节落本地后即可离线显示。底栏「浏览记录」按钮同样支持单击回顶，已在顶部时单击不做任何操作。
- **首页两个板块**：底部导航在「和谐动漫-兽人向」与「和谐游戏-兽人向」之间切换，启动默认进「和谐动漫-兽人向」；两者都是一级页，切换不压栈、不重载。冷启动只刷新「和谐动漫」，游戏板块先铺上次的本地快照、不在后台偷偷请求；冷启动后第一次手动切到「和谐游戏」时自动联网刷新一次，之后再来回切换只复用已有列表。
- **帖子列表**：标题 / 分类标签 / 作者 / 时间 / 回复数 / 查看数，正文首图回填预览（1 张整宽、2–3 张横排、≥4 张九宫格）。下拉刷新采用「重叠布局」：刷新动画藏在列表下面，下拉时列表跟手下移把它露出来，转圈速度跟手（停手减速），刷新完成后列表才慢慢回顶盖住；只有手指按住时才算下拉，惯性甩回顶部不会误触。列表上左右滑动可直接在「和谐动漫 / 和谐游戏」之间切换。
- **帖子详情**：正文分段渲染（文本 / 图片 / 内联超链接 / 折叠块 `[spoiler]`），评论区楼层、页码、评分统计；正文内嵌附图与付费附件（大小、下载次数、售价、阅读权限）单独成块。末尾图片附件已经补进正文大图时，附件区自动隐藏对应的图片文件，不再重复列一遍。
- **交互**：回复、评分（血液 / 追随 / 堕落）、购买附件、下载附件、跳到浏览器打开外链；所有输入场景打开后自动聚焦并唤起键盘，输入光标跟随 COUI 主题色。
- **附件购买与下载**：购买成功后优先从帖子页/购买页提取站点签名下载链，买完直接下载；附件保存前严格拒绝 `text/html`，`.txt` 也不例外，避免把提示网页存成附件。有阅读权限或金币要求的附件会先弹窗说明信息与要求，确认后才下载；购买前先核对金币余额，不足直接提示「需要 X / 当前 Y」，站点权限/金币提示也会原样读出；购买页用应用内 HTTP 直取，确认后 POST 购买表单，成功即下载；已经付过费或本来就免费的附件点一下直接下载。下载走 App 内置下载器，附件卡片里有横向进度条，完成按附件块偏移一次定位，不再从顶部闪回；文件落到 App 私有目录 `files/attachments/<tid>/` 并与原帖关联。
- **txt 附件内联阅读**：txt 下载完直接把正文替换进附件区，链接可点；因为正文已经内联，这张附件卡只给「复制全文」「自由复制」，其他格式才保留「打开文件」交给系统应用。「自由复制」弹出高度自适应内容的文本窗口，可长按选中复制，链接同样可跳转。
- **附件管理**：设置页里的独立页面（「帖子缓存」上方），列表按类型显示文件图标 + 不限行文件名，右侧「查看原帖」「查看文件」；支持长按多选、批量删除，整套选择模式与浏览记录一致。
- **底栏布局**：四个板块（和谐动漫 / 和谐游戏 / 收藏 / 浏览记录）的导航胶囊与右下角搜索按钮排成一行、作为整体水平居中于底部，二者间距 8 dp。四个按钮都可对当前页做手势：「和谐动漫」「和谐游戏」单击回顶、300ms 内双击刷新（已在顶部时单击直接刷新）；「收藏」「浏览记录」只做单击回顶，已在顶部时单击不做任何操作。按住拖动切到别的板块时，不触发这些手势。
- **搜索**：独立页面，进页自动聚焦，带搜索历史；命中站点频率限制时给出明确提示。再次搜索同一个关键词时先拿内存 / 磁盘里的旧结果铺屏，后台拉新结果后替换，刷新动效与首页同一套；每次进入搜索页都会清空结果列表的滚动位置。
- **登录**：登录页是一个可交互的 WebView，右上角 ✓ 表示「登录完成」，也会实时监测 Cookie 并在拿到后询问是否回首页刷新；站点要求 Cloudflare 验证时会弹一个可见的「站点验证」页让页面自己跑完。
- **多账号**：设置页「账号管理」保存多份 Cookie 快照（头像 + 昵称），可点选切换、点垃圾桶删除；删除当前账号会自动切到下一个，一个不剩就回到未登录引导；新增账号时先腾空 Cookie 再开登录页，取消则恢复原账号。
- **顶栏与菜单**：右上角头像点开 COUI 风格浮窗菜单，菜单项按当前页面组装：未登录时首项为「登录」，帖子页有「分享 / 复制链接 / 用浏览器打开 / 刷新」，「设置」始终存在，今日自动任务失败时再加「手动签到 / 手动抽卡」；只有一项时直接执行，设置页与附件管理页里点头像不再展开菜单（避免把自己再打开一次）。菜单项支持按住拖动：白色高亮块跟随手指 Y 移动，拖出菜单后仍跟随，松手在菜单外则不执行任何项并复位消失；直接点按不会从首项闪过。选择模式右上角固定为与返回等大的双对勾「全选」。
- **图片查看器**：全屏沉浸式内置查看器，支持双指缩放（以手指中点为锚点）、双击缩放（以点击位置为锚点）、放大后拖动与越界阻尼回弹；多图可左右滑动切换，底部圆点页标（当前页更大）；放大后拖到边缘继续拖可切入上/下一张，无图可切时回弹。每张图的缩放与位移独立保存，切走再切回仍是原来的放大边缘。折叠块（`[spoiler]`）里的图片同样进入查看器序列。
- **界面与动效**：COUI（ColorOS 17）风格；顶栏「26dp 渐隐区 + DstIn 渐变遮罩」的渐变模糊，导航栏 / FAB / 头像菜单同款背景模糊（设置页可切回经典纯色）；帖子卡片 → 详情页为 0.5s 的容器变换：实时录制的卡片内容层从卡片矩形等比铺满全屏（卡片内容先放大淡出、详情内容后段淡入），退回反向；不同列表之间切换不触发该动画。
- **内容偏好**：设置页「账号管理」下方有「内容偏好」，分屏蔽词与特别关注两组，支持换行批量录入、逐条删除。屏蔽词命中的帖子直接从首页列表消失，特别关注命中的帖子标题前加 ✨；规则只作用于首页四个板块（和谐动漫 / 和谐游戏 / 收藏 / 浏览记录），搜索结果和外部链接不受影响。
- **已读标记**：打开过的帖子在列表里整卡压暗（预览图和文字一起降亮度，叠一层 45% 黑色遮罩），保留彩色、不转黑白；搜索结果同样显示已读态。已读只记 tid，独立存放，删浏览记录、清缓存都不影响。
- **每日任务**：设置页「自动任务」可分别开关自动签到、自动抽卡，每天首次启动只执行开启的任务，过程中有对应提示，结束时汇总成功/失败；签到成功会读取页面「积分奖励」并提示获得多少枚金币，抽卡成功会读取「我的抽奖」最新记录并提示抽到的卡片与积分奖励；全新安装默认关闭，从旧版本升级保留开启。判定看动作接口返回而不是重载页面，避免超时误判；执行失败时头像菜单会出现手动入口，点击用系统浏览器打开对应页面。
- **深链与分享**：`https://www.gamemale.com/thread-*` 可直接打开详情；也接收系统分享面板来的帖子链接。
- **缓存**：帖子整页 HTML、正文图片、列表预览图、已下载附件都算内部缓存并落盘，重进不重复联网；默认上限 300 MB，可在设置页改成 100 / 300 / 500 / 1000 MB 或手动清除。清缓存会连附件一起删，删除前二次确认；超限时先清帖子缓存，附件留到最后才按最旧清理。
- **设置页**：设置页是独立整页层（不是根页面原地重渲染），进入与退出统一淡入淡出；账号管理、内容偏好、附件管理这些次级页面同样是独立整页层。设置页包含账号管理、内容偏好、界面风格（COUI 模糊 / 经典纯色）、字体大小、深色模式（跟随系统 / 常亮 / 常暗）、附件管理、缓存上限与清理、导出诊断日志、关于页（含历代更新日志）。
- **诊断**：本地滚动日志（请求地址、耗时、字节数、解析结果、失败原因），设置页可一键导出，排查加载异常时不用连电脑。
- **首次启动声明**：新装或从旧版本升级到新版本后弹一次使用声明，说明本应用为个人学习研究作品、不得用于商业用途，并说明内容版权归属与本地数据范围；确认后不再打扰。
- **关于与致谢**：设置页「关于」列出项目发起人 chain355、功能代码编写 豆包、UI 细节优化 orz12（可点开 GitHub 主页），并附历代更新日志；新增功能统一以 `✨` 置顶、调整与修复为灰色条目排在后面。

## 技术结构

```
app/src/main/java/com/gamemale/client/
├── MainActivity.kt   // 状态机、导航、登录、评分/回复/搜索、图片与缓存调度
├── Ui.kt             // 全部 Compose 界面（顶栏、列表、详情、弹窗、设置页）
├── Site.kt           // 数据模型 + Jsoup 解析（板块、帖子、表单、附件、折叠块）
├── Fetcher.kt        // 隐藏 WebView 取数、POST、页面内表单提交（请求串行队列）
├── ThreadCache.kt    // 整页缓存 ThreadCache、图片 ImageStore、预览图 ThumbStore、列表快照 SnapshotStore
├── Accounts.kt       // 多账号 Cookie 快照（accounts.tsv + current_account.txt）
├── HistoryStore.kt   // 浏览记录（filesDir/history.json，最多 300 条）
├── WatchStore.kt     // 收藏（filesDir/watch.json，最多 200 条）
├── ReadStore.kt      // 已读 tid（只记 tid，与浏览记录各自独立）
├── ContentPrefs.kt   // 内容偏好：屏蔽词 / 特别关注（只作用于首页四个板块）
├── AttachmentStore.kt  // 附件下载记录与进度
├── Changelog.kt      // 历代更新日志，按「新增 / 调整 / 修复」分类
├── Diag.kt           // 本地滚动诊断日志（filesDir/logs/app.log）
├── Theme.kt          // COUI 主题、Monet 动态取色、深色模式
└── App.kt
```

几个绕不开的关键点（改代码前建议先看）：

1. **模板钉桌面版**：站点按 UA 下发手机模板 `template/mwt2`，桌面节点根本不存在。所以所有请求统一附加 `mobile=no` 并写同名 Cookie，**但不改 UA**——伪装桌面 UA 会直接触发 Cloudflare 600010。
2. **单 WebView 必须串行**：`Fetcher` 只有一个 WebView，两个请求并发会互相覆盖回调，出现"A 帖的预览图贴到 B 帖""点开 N 显示 M"这类错乱。所有取数请求都进 `Fetcher` 的队列依次执行，并且拿回 HTML 后要校验 `thread-<tid>` 是否对得上。
3. **解析不进主线程**：600 KB 级页面用 Jsoup 解析很吃内存，集中在主线程会 `OutOfMemoryError`。预览图解析走独立后台线程，整页缓存在内存里按 3 MB 总量封顶，同时开了 `android:largeHeap`。
4. **图片必须带 Referer**：图片域会 403，Coil 的 OkHttpClient 要注入 `Referer` 与 Cookie。
5. **评分表单是文本框**：`input[name=scoreN]`（血液 `score3`、追随 `score4`、堕落 `score8`），分值上限在旁边的 `#scoreoptionN` 列表里；提交必须带 `ratesubmit=yes`。
6. **成功/失败不要只看返回值**：站点成功时会在返回 XML 里混入"回复奖励"文案，容易误判。回复改为提交后重新抓帖子页、用刚发内容做探针核对；只要没有 `errorhandle_` / `alert_error` 就算成功。

## 构建

要求 JDK 17、Android SDK（`compileSdk`/`targetSdk` 37、build-tools 37.0.0）、Gradle 9.6、AGP 9.4.1、Kotlin 2.4.20。

```bash
# 1. 指向自己的 SDK
echo "sdk.dir=/path/to/android-sdk" > local.properties

# 2. 一条命令出包 + 核验版本号（带超时与自动重试）
./build.sh
```

`build.sh` 会从 `app/build.gradle.kts` 读出版本号，`timeout` 包裹 Gradle，失败或版本不符自动重试（默认 3 次），然后用 `aapt2 dump badging` 核验 `versionCode`/`versionName`，最后输出 `Gamemale-<版本>.apk`。

也可以手动执行：

```bash
zipalign -f -p 4 app-release-unsigned.apk aligned.apk
apksigner sign --ks your.keystore --out Gamemale.apk aligned.apk
```

> `gradle.properties` 里 `-Xmx1536m` 不要调小，否则 Kotlin 编译阶段容易 OOM。

## 已知限制

- 解析依赖站点现行模板，站点改版会失效。App 内置诊断：出错时可把当前 HTML 导出到 `下载/gamemale-debug.html`，方便比对修复。
- 列表页站点本身不提供缩略图，预览图只能逐帖抓正文首图，所以会延迟出现；已缓存的帖子直接从本地读，不再联网。
- 评分默认提交各维度最大合法分值，没有做逐项微调界面。
- 内置的浏览器取数依赖 Android WebView，非 Android 平台无法直接复用。
